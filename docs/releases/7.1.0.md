## What's new in 7.1.0

- **CloudStream on iPhone (and any phone or computer browser).** Run the new server mode on a free Oracle Cloud
  server (or any always-on Linux machine) and open your own private address in Safari. It works anywhere, also over
  mobile data, and sits on your Home Screen like an app: Home, Search across all extensions, title pages, the player
  (sources, subtitles, next-episode countdown, picture-in-picture, AirPlay), Continue Watching, My list, Live TV and
  profiles, behind your password. One command installs it with free HTTPS:
  **[step-by-step guide](https://github.com/sherazi5110/cloudstream-Linxdroid/blob/main/docs/WEB-APP.md)**.
- **Backup and restore from the command line** (`cloudstream-linux backup` / `restore`), to copy your setup from the
  Linux or Android app to the server.
- Includes everything from 7.0.1 (the Settings fix on Linux).
