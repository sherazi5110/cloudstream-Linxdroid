## What's new in 7.1.0

- **CloudStream for Windows.** The same app as on Linux (look, profiles and kids mode, extensions and repositories,
  Stremio add-ons, Live TV with the guide, downloads, skip intro, the next-episode countdown, backup and restore)
  for Windows 10 and 11, with its own Java and **VLC included**, so there's nothing else to install:
  - `cloudstream-windows-7.1.0.msi`: installs for your user (no admin password), with Start-menu and desktop shortcuts.
  - `cloudstream-windows-7.1.0-portable.zip`: unzip anywhere and run `CloudStream.exe`.

  The installer isn't code-signed yet: if Windows says *"Windows protected your PC"*, click **More info → Run anyway**.
  A backup from the Linux or Android app restores on Windows too.
- Linux, Android: everything from 7.0.2 (every extension loads on Android like in the official app).
