## What's new in 7.2.0: Stream Goat

- **New name and logo: Stream Goat.** A mountain goat standing on snowy peaks, on every app (Windows, Linux,
  Android, Android TV and the web version), its icons and the installers. Settings → About says
  *Created by Syed Ali Hamza*. Your extensions, profiles, library and downloads are kept: on Windows they move
  from `%APPDATA%\CloudStream` to `%APPDATA%\Stream Goat` by themselves.
- **Startup intro.** Peaks rise out of a night sky, an arc of stars sweeps over the summit and the goat appears
  (about 3 seconds; click, tap or any key skips it). Turn it off in Settings → Appearance → Startup animation.
- **Search suggestions.** Start typing a title and suggestions drop down (from TMDB if you've added a key,
  otherwise Cinemeta); arrow keys and Enter pick one. Desktop, Android and the web version.
- **Translate subtitles.** In the player: Subtitles → *Translate subtitles to…* English, Hindi, Urdu, Chinese,
  Spanish, French, Arabic, Bengali, Portuguese, Russian and 14 more. It takes the subtitles you're using (or the
  first ones on offer), translates them with Google's neural translation keeping every line's timing, and
  switches to them. Translations are saved, so watching again is instant. It works on subtitle files (SRT,
  WebVTT), not on subtitles burned into the picture. Windows, Linux and Android.
- **Anime enhance** (Windows, Linux). Low-resolution animation is upscaled to your screen inside VLC with
  Lanczos instead of a soft stretch, so line art stays crisp. Measured on a 240p cartoon shown at 720p: closer to
  the original (26.8 → 27.4 dB PSNR). Auto for anime and cartoons; also in the player's Picture menu (Z).
- **HDR.** Android: HDR10, HLG and Dolby Vision sources play in real HDR on HDR screens (Settings → Player →
  HDR). Windows, Linux: the player can't send HDR to the screen, so HDR sources get a colour correction instead
  of looking grey and washed out (Auto for sources marked HDR / Dolby Vision; Picture menu, Z).

File names changed with the name: `streamgoat-windows-7.2.0.msi`, `streamgoat-linux_7.2.0_amd64.deb`,
`streamgoat-android-….apk`. On Linux the package is still `cloudstream-linux`, so the new .deb updates the old one.
