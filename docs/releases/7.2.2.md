## What's fixed in 7.2.2

- **Android: typing in Search works again.** Since 7.2.0 the search box showed the last search instead of what
  you were typing, so key presses seemed to do nothing. Type, then press Search (or pick a suggestion).
- **Android: the start animation always opens the app.** On some devices it stayed on screen until you tapped
  or turned the device. It now ends on its own after a few seconds whatever happens; a tap or any key skips it.

Everything from 7.2.1 is included: Windows keeps your extensions after a restart, Home no longer jumps to the
top, extensions like Eclipsia (repository 759) work on Windows and Linux and play their best link, and Android
has a ⚙ button for extensions' own settings.
