## What's new in 7.0.2

- **Android: every extension installs and loads, like in the official app.** Some extensions (for example
  MovieBoxProviderIN from the CNC repository) failed with *"Failed resolution of: Landroidx/appcompat/…"*. The app now
  includes the same libraries the official CloudStream app gives extensions (AppCompat, Fragments, Preferences,
  Material, ConstraintLayout, Lifecycle, Navigation, WorkManager, Gson, FuzzyWuzzy, Conscrypt, Zipline), and the
  official app's own classes that extensions call: **CloudflareKiller** (gets past Cloudflare protection), the app
  events, plugin and repository managers (for Ultima, StreamPlay, StremioX), resume-watching, profiles, AniList data
  and player types. Checked against all 127 extensions of the Phisher and CNC repositories: nothing they use is missing.
- The app's screen is now an AppCompat activity, as in the official app, so extensions' own settings screens open.
- The web version (sherazi5110.github.io/cloudstream-Linxdroid) explains add-ons that need setting up (debrid etc.).
