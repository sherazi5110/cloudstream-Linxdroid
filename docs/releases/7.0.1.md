## What's new in 7.0.1

A fix-up for 7.0.0. If you have 7.0.0, install this over it (Linux and Android).

- **Fixed (Linux): the Settings button did nothing.** A mistake in 7.0.0's new "Preferred media" setting kept the
  Settings page from opening. Settings now also opens if one section fails, showing what went wrong in that section.
- An extension that doesn't say which language it is no longer causes problems in the language filter.

Everything from 7.0.0 is included: downloads, skip intro, the next-episode countdown, the TV guide, "Wrong match?",
the fixed source switching (no more jumping to the next episode), all search results, repository search, and the new
settings (extension languages, preferred media, backup and restore, test all extensions, and more).
